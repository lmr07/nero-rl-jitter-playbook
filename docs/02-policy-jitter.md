# 02 定位 actor 反向输出并修复训练

## 把链路拆开观察

每个控制周期保存 `goal → actor raw → 限速前绝对位置请求 → 限位/限速后目标 → CAN 本地回显 → q,dq`，并保存前一拍 actor 动作和观测历史。固定末端目标时统计每轴目标增量的反向率、限速饱和率、目标及位置 5 Hz 以上 RMS，以及末端位置/姿态误差。分清 50 Hz 控制记录和约 200 Hz 反馈的带宽；软件本地回显只能证明主机发送版本，不能证明电机内部生效时刻。

### 此次因果证据

1. 旧版在目标不动的初始区间，J1 关节角范围约 1.098 rad，J5 约 1.047 rad；两组关节向量相距 1.58 rad，末端位置仅相距 0.015 m。7 自由度冗余让末端奖励无法单独约束关节往返。
2. 2026-10-26 另一批策略在实物及无噪声仿真中都有约 12.5 Hz 目标周期；P1 保持时多轴目标经常打满 0.03/0.04 rad 的逐拍限速，典型是 `++--`，并非每拍反向。冻结发送目标后，仿真中的对应位置高频 RMS 降至接近零；冻结物理反馈后该局部目标周期仍存在。由此可排除“固定目标下 PD 必然自激”和“观测噪声是周期必要条件”的解释。
3. 在固定物理反馈的策略递推实验中，保留动态 previous-action 通道即可维持局部周期，冻结该通道后收敛；这说明该状态下上一拍动作反馈可形成自主离散闭环。它是诊断结论，不意味着实物部署时应冻结该观测。
4. 实物增益保持阶段在当时 home 姿态没有可分辨的同等持续振动；但其他姿态、负载和摩擦条件仍需单独验证。CAN 的 BCM 发送与 50 Hz 更新不同步时偶尔跳过中间目标，使相邻回显目标跨过两拍，属于独立的链路风险。

以上证据分别来自不同日期、checkpoint 和姿态；它们组成排查逻辑，不是单次严格配对的消融实验。

## 训练中的有效改动

最终稳定版使用 7 关节绝对位置动作。先根据动作得到**原始绝对角请求**，再限制关节角余量及单拍变化。J1/J2 限 1.5 rad/s，即 20 ms 内 0.03 rad；J3–J7 限 2 rad/s，即 0.04 rad。单有限速只能降低传到实物的幅值，不能保证 actor 不持续反向，因此训练同时惩罚：

- 限速前请求的逐拍变化，防止 actor 在限速器背后大幅过驱；
- 原始请求与实际下发目标之间的差距，令策略学会遵守动作接口；
- 保持阶段的关节速度、加速度和下发目标变化；
- 末端确已收敛时相对关节锚点的漂移，避免利用冗余自由度来回切换。

初始角 `[0,-1,0,1.8,0,0,0.3]` 的工具 pitch 约 `-0.4708 rad`，而水平姿态目标是 0。稳定版让初始姿态目标逐步过渡到水平，并用 URDF 重力平衡计算初始位置驱动目标；这减少了刚启动时“位置对了但姿态不对”和重力导致的闭环修正。夹爪质量随机化在该版关闭，以保持初始化一致。

限位版在稳定版基础上增加 J1–J6 目标角余量 `0.16 rad`、J7 `0.30 rad`，对 `q + 0.15*dq` 的预测越界加惩罚和终止，针对旧策略在 J7 `q=1.321 rad, dq=1.205 rad/s` 的实物停机事件。最终 checkpoint 是稳定版 10000 轮权重的续训，优化器从零开始，再训 10000 轮；不是从随机初始化直接训练该限位版。

## 不应误判的现象

- 末端误差小、总奖励高，仍可能关节大幅往返；应以关节目标和反馈指标联合验收。
- 降低部署端限速或加低通可能减小关节运动，却可能损害跟踪，也未消除 actor 的反向请求；改变动作映射后应重新训练。
- 训练随机动作噪声不等于部署时的随机推理。若无噪声确定性回放仍振荡，先看动作递推与奖励作用点。
- 仅统计限速后的 `candidate` 会掩盖限速前的大幅请求。记录名称要与实际信号位置一致。
